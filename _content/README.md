# Arxiu editorial anterior

Els fitxers Markdown d’aquesta carpeta pertanyen a una versió anterior del portal. Es conserven com a material de consulta, però no són una font de dades activa ni formen part del flux de publicació.

La web actual es compon de pàgines HTML amb Web Components natius. El catàleg interactiu es deriva d’aquestes pàgines mitjançant `python3 _scripts/sync-catalog.py`; no hi ha cap procés que convertisca aquests Markdown en pàgines.
