❓ Repte i intenció

Com podem dissenyar un recorregut per portar un llibre fictici a tres espais i inventar una recomanació sense copiar cap sinopsi?

Connectar seqüenciació tangible i llengua oral, planificant destinacions i creant missatges breus pensats per a una audiència.

Abans de començar

Prepareu llibres buits o cobertes inventades sense títols coneguts, tres estacions de paper i una graella original. Confirmeu quins blocs del Coding Set teniu i recordeu que el robot no transporta càrregues si això dificulta el moviment.

📅 Seqüència didàctica

  1. Creem un llibre fictici. En equips, inventeu un personatge, un lloc i un problema per a una història breu. Dissenyeu una coberta amb formes i trieu una recomanació de dues frases. Evidència: coberta i missatge creats pel grup.
  2. Planifiquem les parades. Situeu el punt de préstec, la zona de lectura i la prestatgeria en el mapa. Acordeu quin ordre té sentit per a la missió i escriviu una ruta amb peces o símbols abans de programar. Evidència: seqüència amb destinacions i justificació.
  3. Executem i depurem. Introduïu els blocs, comproveu el punt final i reviseu si el programa visita les tres parades. Canvieu només una instrucció cada vegada i repetiu des del mateix punt d’inici. Evidència: ruta revisada amb registre d’un error.
  4. Fem una recomanació. El robot recorre el mapa mentre el grup comparteix el llibre fictici a les estacions. Compareu dues rutes i expliqueu quina facilita més l’escolta, l’accés o la claredat del relat. Evidència: itinerari i presentació oral o visual.

📋 Avaluació i evidències

Observa si la seqüència arriba a les destinacions previstes, si l’equip revisa el programa amb proves i si comunica un relat original amb ordre i intenció.

♿ Més d’una manera de participar

Oferiu dictat a una persona adulta, pictogrames, comunicació augmentativa o presentació només amb la coberta. Reduïu les destinacions o accepteu una demostració amb fitxa si l’accés al robot és una barrera.

🔗 Referents oficials i adaptació

El mapa a escala i l’itinerari guiat adapten MatataBot’s Guide, que proposa crear un mapa escolar, preparar una visita i programar el robot per recórrer-la. La parada de préstec i l’entrega de llibres ficticis també reinterpreten la idea de destinacions de Deliver Animals. El nostre mapa, relat, personatges i materials són propis i no demanen construir maquetes d’edificis.
