# Format i cobertura funcional dels tutorials

Totes les fitxes de `_content/tutorials/` comparteixen les mateixes metadades obligatòries (`title`, `description`, `robot`, `level`, `duration`, `order`, `image`) i la mateixa plantilla en el mateix ordre: repte i objectius, materials i preparació, funcions del robot treballades, seqüència guiada, prova i reflexió, accessibilitat i seguretat, evidències d’aprenentatge, i fonts oficials i límits. Les imatges i els blocs de codi s’intercalen dins dels apartats pertinents; no creen una estructura alternativa.

La cobertura és una propietat del conjunt de tutorials de cada robot, no cal que cada fitxa explique totes les funcions. Una funció només es considera coberta quan hi ha una guia executable, proves observables i els límits del maquinari. Els accessoris o extensions que no formen part del kit base s’identifiquen com a opcionals.

La matriu és una auditoria inicial, no una declaració de cobertura completa. Les mancances s’han de convertir en tutorials propis i passar per la mateixa plantilla i els mateixos criteris de verificació abans de considerar acabat l’objectiu.
