# Format i cobertura funcional dels tutorials

Totes les fitxes de `_content/tutorials/` comparteixen les mateixes metadades obligatòries (`title`, `description`, `robot`, `level`, `duration`, `order`, `image`) i la mateixa plantilla en el mateix ordre: repte i objectius, materials i preparació, funcions del robot treballades, seqüència guiada, prova i reflexió, accessibilitat i seguretat, evidències d’aprenentatge, i fonts oficials i límits. La seqüència es presenta amb passos numerats, les preguntes de comprovació amb una llista i els materials, funcions i evidències amb elements escanejables. Les imatges i els blocs de codi s’intercalen dins dels apartats pertinents; no creen una estructura alternativa.

La cobertura és una propietat del conjunt de tutorials de cada robot, no cal que cada fitxa explique totes les funcions. Una funció només es considera coberta quan hi ha una guia executable, proves observables i els límits del maquinari. Els accessoris o extensions que no formen part del kit base s’identifiquen com a opcionals.

La matriu és una auditoria viva; les 34 fitxes tenen plantilla comuna, però la cobertura funcional només es considera completa després de verificar cada funció contra la dotació física i les versions de programari de cada centre. Les mancances s’han de convertir en tutorials propis i passar per la mateixa plantilla i els mateixos criteris de verificació abans de considerar acabat l’objectiu.
