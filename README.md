# 🤖 Robòtica200 — Robòtica per a docents

Portal web educatiu net, espaiós i de **baixa densitat d'informació**, enfocat a facilitar la tasca dels mestres i professors a l'aula.

---

## 🌟 Estructura Principal (3 Apartats)

Al entrar a la web, hi ha exclusivament tres apartats clarament diferenciats:

### 1. 💡 Pensament computacional
Activitats **desendollades** (sense pantalles ni ordinadors) per treballar els fonaments lògics mitjançant el moviment, el joc i materials d'aula:
- *El Robot Humà i el Llenguatge Precís* (Lateralitat i instruccions unívoques).
- *Dibuix per Píxels i Imatges Binàries* (Com representen les dades les pantalles).
- *Xarxa d'Ordenació al Terra (Sorting Networks)* (Algorismes de comparació paral·lela).
- *El Laberint d'Instruccions i Detecció d'Errors (Debugging)*.
- *El Joc dels Condicionals (Si... Llavors... Si no...)*.
- *Missatges Secrets i Xifratge Cèsar* (Criptografia i privadesa).

---

### 2. 🤖 Robòtica
Tutorials dedicats als **6 robots d'aula**:
1. **Coding Express:** Tren de fusta DUPLO amb maons d'acció de colors (vermell, blau, groc, verd, blanc).
2. **TaleBot:** Robot de terra interactiu que parla, llegeix mapes i dibuixa amb retoladors.
3. **CodingSet (Matatalab):** Programació tangible sense pantalles amb torre d'escaneig i fitxes dures.
4. **CodeyRocky (Makeblock):** Controlador amb pantalla matriu LED de 16x8, sensors i tracció oruga.
5. **Spike (LEGO Education):** Construcció Technic avançada, motors angulars amb mesura de gir i sensors d'ultrasons/color.
6. **Microbit (BBC micro:bit):** Placa versàtil amb matriu 5x5 de LEDs, sensors de llum/moviment, ràdio i pins de connexió.

---

### 3. 📑 Situacions d'aprenentatge
Catàleg de propostes didàctiques curriculars amb sistema de **filtres combinables**:
- **Robot:** *Tots, Coding Express, TaleBot, CodingSet, CodeyRocky, Spike, Microbit, Desendollat*.
- **Cicle:** *Tots, Infantil, Cicle Inicial, Cicle Mitjà, Cicle Superior, ESO*.
- **Temàtica:** *Medi ambient i sostenibilitat, Ciutat intel·ligent, Salut i benestar, Art i música, Exploració espacial, Convivència i ciutadania*.
- **Matèria:** *Coneixement del Medi / Ciències, Matemàtiques, Llengua, Educació Artística, Tecnologia i Digitalització*.

Cada situació inclou el repte conductor, les competències clau, la seqüència temporal de sessions i els criteris d'avaluació.

---

## 🚀 Com obrir la web

- **Opció directa (100% Offline):** Obre l'arxiu `index.html` amb qualsevol navegador web fent-hi doble clic.
- **Opció amb servidor local:** Executa `./iniciar.sh` a la terminal i obre [http://localhost:3000](http://localhost:3000).
